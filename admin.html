This page is intended for Nauza Tu administration. It is not a secure login-protected administration system. Do not publish or advertise this page as a public admin portal.

Payment must be independently verified before activating a paid promotion.

1. Vehicle Information

Enter the approved vehicle information exactly as it should appear in the marketplace.

2. Seller / Advertiser Information

Enter the seller details supplied with the advertisement.

3. Promotion & Approval

Select the advertising package after confirming the seller's payment status.

Package information:
Free Listing — No paid promotion.

4. Payment Verification Record

Keep the payment information together with the listing record.

5. Generate Vehicle Listing

Generate the JavaScript object and paste it into vehicles-data.js.

How to Use This Tool

  1. Receive the seller's vehicle information and photographs.
  2. Review the submitted information before approving the vehicle.
  3. Give the vehicle a unique Listing ID such as NT010.
  4. Upload the approved vehicle photographs into the images folder.
  5. Enter the image filenames/paths in this tool.
  6. Select the seller's advertising package.
  7. Verify payment before activating a paid promotion.
  8. Select Featured when the listing should appear in the Featured Vehicles section.
  9. Tick Approved only after the listing has been reviewed.
  10. Click Generate Listing Code.
  11. Copy the generated object.
  12. Open vehicles-data.js in GitHub.
  13. Paste the new object inside the vehicles array.
  14. Commit the changes.
  15. Check the Vehicles page and confirm the listing appears correctly.
Important: A paid promotion should only be marked Payment Verified after you have actually confirmed the M-Pesa transaction.
